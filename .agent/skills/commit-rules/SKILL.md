# JAM Git Standards

Use this skill when preparing commit messages, committing changes, or pushing code to repositories.

## 📝 GIT COMMIT & PUSH RULES

- **Header**: Short, readable, max 60 characters.
- **Body**: Detailed description of changes (why and what).
- **CRITICAL**: Before pushing to `main` or `develop`, you MUST ask for user confirmation or if they want to create a new branch.
